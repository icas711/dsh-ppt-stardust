## Исправление ru.37

Рендер извлекает только объявленные встроенные лица через отношения презентации. EOT декодируются без изменения таблиц sfnt. Проверяются форматы, не более 64 ссылок, 12 MiB на лицо и 32 MiB суммарных уникальных декодированных файлов. Идентичные файлы дедуплицируются по SHA256.

Для задания создаётся отдельный временный каталог с именами файлов по хешу. Он передаётся в `createConverter.fontDirectories` перед обычными системными/пользовательскими каталогами. Без встроенных шрифтов остаются настройки SDK по умолчанию. При явном списке каталогов автоматическое дополнительное обнаружение приватных шрифтов Office в SDK не выполняется; обычные системные каталоги сохраняются. Шрифты не устанавливаются в ОС и не добавляются в выдачу. Удаление происходит после `dispose`, включая ошибку создания конвертера, ошибку экспорта и отмену.
