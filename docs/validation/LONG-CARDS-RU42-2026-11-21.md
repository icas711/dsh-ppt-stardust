## Изменение

После первой сетки cards компоновщик пробует широкие строки с жирным названием слева и полным пояснением справа. Кандидат доступен только для широкой области и при наличии detail у каждого элемента. Иконки сохраняются над названием. Размеры текста берутся из шаблона, autoFit не включается. Слова названия должны помещаться целиком; высота всех строк проверяется до создания результата. При нехватке места остаются прежние композиции и разрешённая вызывающей стороной пагинация. Произвольный длинный текст не обязан помещаться на одной странице.
