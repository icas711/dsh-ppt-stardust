# Исправления ошибок инференса — локальная проверка

Дата: 20.11.2026. Исходный план: [FIX-PLAN-INFERENCE](../FIX-PLAN-INFERENCE-2026-11-20.md).

## Реализовано

- `result()` и `checkDeck()` возвращают строковый заголовок метаданных, включая scene-слайды без `label`. Пустое имя не становится `undefined`.
- `ppt_check {deckPath, slide}` возвращает один полный `selectedSlide`, включая стили, геометрию и декор. Чтение не меняет файлы.
- `ppt_edit ... patch.elementUpdates:[{id,changes}]` обновляет существующие объекты, сохраняя остальные и их порядок. ID/тип менять нельзя. Поля заменяются целиком; `textStyle` объединяется с исходным. Режим не смешивается с полной заменой `elements`. Старая семантика массивов сохранена.
- Явный `color` сбрасывает унаследованный `colorSpec`. Если оба явно переданы в одном стиле, используется `colorSpec`. Комбинация стилей шаблона использует общий алгоритм. HTML вычисляет эффективный цвет/альфу; PPTX сохраняет исходные transforms.
- Схемы и сообщения различают EMU и pt. Обводки фигур/линий и границы таблиц принимают дробные значения 0–100 pt; 0,75 pt экспортируется как 9525 EMU. Ошибки композиции адресуют номер слайда, ID/имя объекта и роль.
- Инструкции восстановления требуют проверить известный проект после ошибки ответа и сначала рассмотреть undo. Уточнены новый ID/история при `overwrite:true`, конфликты общих файлов и проверка встроенных шрифтов. Диагностика конфликта старого проекта сообщает возможное перезаписывание новым созданием.

## Проверки

`npm test` выполнил сборку TypeScript, клиента и весь набор: **485 tests, 483 passed, 2 skipped, 0 failed**. Длительность финального локального запуска — 16,44 с; это время тестов, не замер инференса модели.

Шесть новых регрессионных сценариев в `test/inference-contract.test.mjs` проверяют:

1. Реальные результаты исполнителей create/edit/check/undo/no-op на JSON round-trip; композицию восьми слайдов и правку трёх объектов на слайде 5, сохранность декора, ID/порядка/геометрии, отклонение устаревшей ревизии и возврат исходной версии через undo.
2. Невалидные изменения без записи JSON/HTML/PPTX; совместимость полной замены, два последовательных шага undo и отсутствие автоматического восстановления декора из `designLayout`.
3. Явные белый/красный цвета поверх унаследованного чёрного `colorSpec`, приоритет явной спецификации и сохранение transforms при изменении несвязанных свойств.
4. Цвет и альфу в HTML при сохранении соответствующего DrawingML в PPTX.
5. Граничные и дробные толщины, XML обводки/границы таблицы, отклонение EMU в поле pt, адресацию контентного объекта после добавления декора шаблона и наличие новых аргументов в схемах инструментов.
6. Два внутренних проекта с одним именем выдачи: разные ID и JSON-пути, новая ревизия 0/пустая история, оба проекта в индексе, неизменность старого JSON и блокирование записи старым проектом поверх новых файлов.

## Что не подтверждено локальными тестами

- Живой инференс в DSH с новой сборкой и исходным пользовательским шаблоном. Серверная среда этого лога здесь недоступна; время, токены и число повторов после исправления не измерены.
- Визуальное совпадение рендера PPTX с HTML и наличие TT Moscow Economy на исходном сервере. Официальный `@deepseek-ai/libreoffice-kit` локально не установлен; PowerPoint и LibreOffice отсутствуют в проверенных стандартных путях. Тесты XML/CSS не являются визуальной приёмкой.
- Два пропущенных теста полного набора — native PowerPoint golden и импорт внешнего PPTX с макетами/картинками/SVG. Они не объявлены успешно выполненными.

Публикация и установка в серверный DSH этим изменением не выполнялись.
