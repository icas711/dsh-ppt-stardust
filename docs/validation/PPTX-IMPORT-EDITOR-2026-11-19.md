# Импорт PPTX и предпросмотр редактора — 19.11.2026

Исправлен воспроизведённый на пользовательском двухслайдовом PPTX сбой отчёта и предпросмотра. Коммит: `adc3f46`. [Машинный отчёт](PPTX-IMPORT-EDITOR-2026-11-19.json).

## Причины и изменения

1. Scene-импорт возвращал layoutCount/pageSize, а UI ожидал прежние layouts/layoutVariants/layoutStats/slide. Поэтому существующие макеты и изображения отображались как нули. Отчёт теперь рассчитывается по фактически созданным семействам, вариантам, размещениям изображений, фонам, заливкам и слотам.
2. `tplFitPreview` вставлял измерительный скрипт в первое `</body>`. В полном HTML проигрывателя первое совпадение находится внутри строки JavaScript, собирающей окно докладчика. Вставка ломала внешний script, оставшийся JavaScript появлялся текстом. Теперь вставка производится перед последним закрывающим тегом body. Синтетический тест проверяет строку с внутренним body и синтаксис обоих скриптов.
3. `saveSubsetFonts=true` означает настройку сохранения, а не доказательство наличия встроенных файлов. Предупреждение «В PPTX встроены подмножества» больше не выдаётся при embedded=0. Настоящие subset-метаданные встроенного шрифта по-прежнему дают предупреждение; положительный тест сохранён. Отсутствующий шрифт остаётся диагностикой, имена в ней очищены от внешних пробелов/дубликатов.
4. Невидимая рамка с нулевой площадью превращалась в unsupported с ошибкой frame.w. Теперь она отражается как пропущенный невидимый объект с именем и слайдом, без фиктивной рамки/ошибки. Коннекторы с нулём по одной оси не отбрасываются. Автоматические номер/дата/колонтитул считаются оформлением и не заменяются образцом пользовательского текста.
5. Редактор выводит messageRu/messageEn по языку интерфейса и показывает слайд/имя объекта. Короткий образец больше не вставляет две одинаково длинные строки в каждый текстовый слот; длинный образец остаётся явной стресс-проверкой. Подсказка описывает реальные макеты schema 3, а не типовые legacy-страницы.

## Проверка исходного файла

После исправления: 2 группы оформления, 2 варианта; 8 размещений изображений, 0 SVG; 2 варианта с заданным фоном, 4 цветные фигуры. Страница сохранена 9906000×6858000 EMU. Это количество размещений/вариантов, а не уникальных медиа-файлов. Во встроенных шрифтах по-прежнему 0 — исходник не содержит доступного встроенного TT Moscow Economy. Настоящее предупреждение об отсутствующем шрифте сохранено.

Нулевая рамка служебного номера отражается в списке пропуска с причиной; invalid-number больше не возникает. Из девяти статических предупреждений образца остаются пять: два неподтверждённых контраста, два выхода объектов за границы и одно предполагаемое переполнение текста. Они не скрыты ради нулевого счётчика.

В браузере открыта изолированная iframe-обвязка с реальным HTML генератора и реальной функцией tplFitPreview. Просмотрены оба макета и проверено переключение. JavaScript текстом не отображается, измеритель передаёт checked=5/count=3. Эти измерения относятся к HTML в данном окружении с отсутствующим исходным шрифтом и не удостоверяют вписывание PowerPoint. Полный UI установленного DSH в этом проходе не запускался.
