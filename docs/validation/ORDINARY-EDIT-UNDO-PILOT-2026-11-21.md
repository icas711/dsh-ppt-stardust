## Сценарий DSH

В одном чистом чате разрешён личный импорт отсутствующего шаблона, затем один ppt_create через requestFile с неизменной контрольной суммой. После создания один адресный ppt_check первой страницы нужен для получения текущих полных paragraphs заголовка. Найти исходный текст «Бюджет 100 тыс. ₽: доли», сохранить структуру и форматирование paragraphs/runs и изменить только текст на «Структура бюджета 100 тыс. ₽».

Один ppt_edit через elementUpdates найденного объекта, с deckPath и expectedRevision из успешного create. Не заменять весь elements, не менять геометрию, оформление и данные. Скопировать пользовательские HTML/PPTX/PDF правки в отдельную папку edited до undo, поскольку undo перезапишет рабочие файлы. Один ppt_undo с путём и ревизией успешного edit, затем сохранить пользовательские результаты в restored. Дополнительные check/render/quality-проходы после успешных операций не требуются. При ошибке остановиться, не создавать проект заново и не угадывать ревизии.

Выдать файлы обоих состояний, предупреждения и короткий текстовый журнал с ревизиями и заменой заголовка. Внутренний проект JSON не прикладывать. Пользователь смотрит изменение заголовка и возврат исходного текста, сохранение остальных объектов и подписей. Визуальную приёмку агент DSH не объявляет.
