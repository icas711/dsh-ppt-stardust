# Обычная табличная генерация в DSH

Дата: 2026-11-21. Проверенная сборка: 0.20.6-ru.23, компоненты 7. Область результата: tableSpec и один пользовательский шаблон public:dkp schema 3. Это не универсальная приёмка всех шаблонов и типов презентаций.

## Подтверждённые результаты

- Реестр из 30 строк: порядок, статусы, повтор заголовков и демо-пометка проверены в серверных артефактах. Исправлен выход пометки за подложку при различиях шрифтов.
- Длинные названия, форматированные числа и проценты, нули и null: шесть строк сохранены, неизвестные значения показаны как «—».
- Частная таблица из DOCX: 12 строк, четыре колонки, многострочные ячейки, пустые абзацы, сноски и автоматическая нумерация Word. После ru.22 высокие строки продолжаются по частям; ru.23 балансирует части и устраняет наследование абзацных отступов темы. Ширина колонок учитывает целые слова.
- Запуск по проверенному JSON, архив 1047: все 12 строк восстановлены из PPTX посимвольно, включая один U+00A0. Проверены все 16 страниц серверного PDF. Размер шрифта таблиц 18 pt, колонки постоянной ширины, прежние разрывы слов в сроках и отдельный короткий хвост устранены.
- Сквозной запуск по исходному DOCX, архив 1103: выданный моделью tableSpec сопоставлен с XML исходника и разрешённой нумерацией Word 1.–12.; заголовки и все ячейки совпали посимвольно. PPTX сохраняет эти значения без изменений, включая U+00A0. Сноски и приписка перед таблицей содержательно сохранены в notes с привязкой к источнику; notes из переданного spec присутствуют в заметках всех 16 слайдов. Просмотрены все 16 страниц PDF, обрезаний и прежних разрывов слов в сроках не обнаружено.

## Передача и границы проверки

В одном промежуточном вызове U+00A0 был заменён U+0020. contentHash остановил изменённый вход до экспорта. Хеш исходного JSON проверен локально тем же модулем; происхождение нормализации по доступному журналу не установлено. JSON с явным escape `\u00a0` после разбора совпал с оригиналом и позволил выполнить успешный запуск 1047. Нельзя пересчитывать или удалять проверочную сумму ради принятия изменённого содержания.

Сценарий обычной табличной генерации на public:dkp закрыт по указанным примерам. Пользовательская оценка общего дизайна, проверка ручного редактирования каждого объекта в Office, наличие TT Moscow Economy на сервере и полный сравнительный пилот восьми компонентов этим отчётом не подтверждаются. В частности, атрибут имени шрифта в PPTX не доказывает отсутствие подстановки в PDF. Числа измерений A/B/C не переносятся на эти обычные вызовы; время, токены и стоимость без предоставленных измерений не восстанавливаются.
