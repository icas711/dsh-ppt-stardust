# Разделение файлов сессий — 19.11.2026

Пользователь сообщил о смешивании временных файлов и плашек файлов под ответом DSH даже в разных чатах. В архиве `dsh-files-20261119-2133.zip` журнал mixed-deck указывает общую рабочую папку `/workspace/exo2`, чтение результатов других прогонов и коллизию `mixed-deck` → `mixed-deck-1`. Журнал — свидетельство модели, а не сырой трассировщик хоста.

## Изменение плагина

- Из доверенных `execution.agent.session.header.owner/id` вычисляется SHA-256; аргументы модели не выбирают namespace.
- Если выбран cwd (включая явный абсолютный cwd), create, предпросмотр тем и экспорт шаблона используют `cwd/dsh-ppt/session-<hash>`.
- Явно выбранная отдельная папка сохраняется; без ID хоста действуют старые пути. CLI не меняется.
- `ppt_render` и автоматический PDF используют `tmp/session-<hash>/render-<UUID>`. Проект сохраняет scope в delivery, поэтому редактирование, отмена, копия и рендер панели сохраняют привязку.
- TTL 90 дней работает для новых и старых managed-каталогов. Неизвестные каталоги и ссылки не очищаются.
- Инструкция модели запрещает искать собственные результаты общим обходом workspace/projects/tmp; дополнительные журналы сохраняются в возвращённом outputDir.

## Открытый дефект DSH

Плагин не рисует плашки файлов под ответом и не формирует пользовательский архив `dsh-files-*`. Разделение каталогов не доказывает исправление этой части UI: общий рекурсивный обход cwd всё ещё может собрать соседние каталоги. Для хоста требуется привязка индекса выдачи и кеша бейджей к sessionId (и владельцу), очистка состояния при переключении чата и ZIP по списку артефактов текущей сессии. Файлы из shell-команд также должны регистрироваться по сессии. Отдельно проверить два параллельных чата, одинаковое имя файла, переключение, reload и скачивание ZIP. Пользователь сообщил, что установлен последний DSH, и отложил работу с хостом в TODO. Локальный исходник другого поколения DSH не считается подтверждением исправления установленного клиента.

Каталоги сессий не являются ACL. Старые общие файлы не удалены и не перенесены.
